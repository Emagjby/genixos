## This file documents the division of responsibilities across GenixOS.

### BIOS

Intializes hardware and begins loading the boot code

### Bootloader

Loads the kernel and prepares its execution environment

### Genix Kernel

Manages memory, interrupts, processes, drivers, and system services

### Genix Shell

Provides an interactive command interface

### Genix WM (To be named)

Eventually provides an _optional_ graphical environment
